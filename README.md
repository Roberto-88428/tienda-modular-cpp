
# Tienda Modular en C++

Taller 1 - Programacion modular en C++

Programa que calcula el total de una compra en una tienda.

El programa pide el precio unitario y la cantidad de unidades, calcula el subtotal, aplica un descuento del 10% si el subtotal es mayor a 100000, y muestra el subtotal, el descuento y el total.

## Archivos
- tienda_modular.cpp: Codigo fuente del programa

## Como usar
1. Compilar el archivo tienda_modular.cpp
2. Ejecutar el programa
3. Ingresar el precio y la cantidad cuando lo pida
